1. How to use this guide

The interface is divided into two sections:

  1. Left panel – Features Available: Displays the reference phenotypes, each illustrated by a representative photograph. Select one or more phenotypes by ticking the corresponding boxes.

  2. Right panel – Entities Remaining: Displays the identification sheets corresponding to the selected phenotypes.

  3. Opening a sheet: Click on the document icon next to a name in the right panel to open the illustrated sheet, including photographs, original descriptions and comparative characters.
